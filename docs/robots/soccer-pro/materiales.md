La arquitectura electrónica y mecánica del robot está pensada para ser modular, permitiendo al competidor equilibrar velocidad de reacción y torque según su preferencia y estrategia de juego:

| Módulo | Tipo de Componente | Criterio de Selección / Recomendación |
| :--- | :--- | :--- |
| **Tracción** | Motorreductores (Fingertech / JSumo) | Relación libre: priorizar mayor reducción para empuje/fuerza o menor reducción para velocidad en pista. |
| **Aros** | Aros con llantas de goma "JSumo" | Garantizar el máximo agarre y fricción en la superficie de combate para evitar el derrape y optimizar el empuje.
| **Control de Motores** | ESC dual o independientes (10A) | Manejo eficiente de picos de corriente e inversión rápida de giro para maniobras ágiles. |
| **Potencia** | Batería LiPo 3S (11.1V) | Máxima entrega de potencia y respuesta inmediata dentro del margen reglamentario de peso. |
| **Electrónica de Control** | Receptor RC inalámbrico | Protocolo estándar de baja latencia con respuesta precisa para la conducción y maniobrabilidad. |
| **Estructura** | Chasis en impresión 3D | Modelado resistente a impactos con alojamiento dedicado para batería y electrónica interna. |
